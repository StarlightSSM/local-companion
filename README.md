# 누리 — 내 컴퓨터 안에서만 사는 AI 비서

돈이 들지 않고, API 키가 필요 없고, 데이터가 밖으로 나가지 않는 개인 AI예요.
모델은 이 컴퓨터의 CPU와 내장 그래픽에서 돌아가요. 인터넷은 뉴스, 웹 검색, 유튜브를 쓸 때만 필요하고,
끊겨 있어도 대화, 정리, 편집, 실험, 일정, 타이머는 그대로 돼요.

## 실행

`start.bat`을 더블클릭하면 브라우저에서 http://127.0.0.1:8780 이 열려요.
(처음 한 번은 필요한 것을 설치해요. Ollama가 꺼져 있으면 같이 켜요.)

## 두 개의 두뇌

왼쪽 아래의 **메인 / 다른 모델** 스위치로 바꿀 수 있어요. RAM 16GB에 맞춰 한 번에 하나만 메모리에 올라가요.

| | 메인 | 다른 모델 |
|---|---|---|
| 실행기 | Ollama | llama.cpp (Vulkan, 내장그래픽 사용) |
| 모델 | qwen3:8b | Qwen3.5-9B (더 최신, 그림도 봄) |
| 이 노트북에서 실측 | 읽기 15 / 쓰기 4.4 토큰/초 | 읽기 13~19 / 쓰기 4.4~5.4 토큰/초 |
| 위치 | Ollama 기본 폴더 | `D:\sumin\local-ai` |

다른 모델을 새로 설치하려면 `setup-alt-model.ps1`을 실행하세요 (약 7GB, 이어받기 지원).

## 키우는 방법

1. **대화로 알려주기:** "내 전공은 통계학이야, 기억해줘" → 🌱 가르치기 탭의 기억에 저장돼요.
2. **대화 끝나고 배우게 하기:** 대화 화면의 `🌱 이 대화에서 배우기` 버튼.
3. **고쳐주기:** 답이 아쉬우면 👎 → "표로 정리해줘" 같은 규칙을 적으면 다음부터 지켜요.
4. **자료 넣기:** 가르치기 → 자료실에 교재·논문을 넣으면 "자료에서 찾아줘"라고 할 때 근거로 써요.
5. **인터넷으로 공부시키기:** "○○ 검색해서 정리하고 메모로 저장해줘" → 저장된 메모는 오프라인에서도 찾아 써요.

모델 자체를 다시 학습시키는 건(파인튜닝) 이 노트북으로는 어려워요. 대신 기억, 규칙, 자료가 쌓이면서
점점 "나를 아는 AI"가 돼요. 나중에 GPU 있는 컴퓨터로 옮기면 `data` 폴더만 가져가면 돼요.

## 다른 기기(폰·태블릿)에서 쓰기

설정 → "같은 와이파이의 폰·태블릿에서 접속 허용" + PIN → 앱 재시작.
실행 창에 표시되는 주소(예: http://192.168.0.5:8780)를 폰 브라우저로 여세요.

## 알아두면 좋은 것

- 노트북 CPU에서 돌아가서 답 하나에 30초~2분 걸려요. 긴 녹음 정리는 몇십 분 걸릴 수 있어요. 기다리는 동안 다른 탭을 써도 돼요.
- 파이썬 실행은 항상 내가 코드를 보고 승인한 뒤에만 돼요.
- 영상·음원 편집은 원본을 건드리지 않고 새 파일을 만들어요(`data/outputs`).
- 사실적인 그림이 필요하면 `setup-image.bat`(약 5GB)을 실행하세요.
- 모든 데이터: `data/` 폴더 (app.db = 대화·메모·기억·일정, outputs = 만든 파일).

## 폴더 구조

```
app/core.py       설정, DB, 검색, 두뇌(Ollama/llama.cpp) 연결, 백그라운드 작업
app/agent.py      대화 + 도구 사용 루프 (도구 목록은 여기)
app/knowledge.py  기억, 메모, 자료실, 녹음 받아쓰기, 공부 정리, 플래시카드, 퀴즈
app/life.py       웹 검색, 뉴스, 일정, 집중 기록, 음악
app/create.py     문서, 영상/음원 편집(ffmpeg), 파이썬 실험, 그림
app/main.py       웹 API
static/           화면 (외부 라이브러리 없음, 오프라인 동작)
```

새 능력을 가르치려면 `app/agent.py`에 `@tool(...)` 함수를 하나 추가하면 돼요.
